# Tok'ra wounded-agent refuge

A Tok'ra cell may discreetly ask the colony to shelter one of its agents after a serious injury or illness.

The request is optional. Ignoring it carries no penalty. Once accepted through the powered Tok'ra communicator, the wounded agent reaches the colony from the map edge and must be carried to safety and treated through normal RimWorld medical care. The symbiote shock is itself a treatable condition, so the operation cannot become stuck if the agent's other wounds heal first.

The agent does not need to recover completely. When they are conscious, mobile and medically stable enough to travel, they prepare to leave. The operation succeeds only after they have actually left the map alive.

The operation fails if the agent dies, is captured, disappears or cannot recover enough before the secure contact window closes. Like other organic Tok'ra opportunities, this event can return later in long games, with hidden delays and anti-repetition weighting.
