# Catégories de stockage

> Statut : Prototype  
> Première catégorie personnalisée : 0.1.31-dev

## Produits biologiques Goa'uld

Les larves de Prim'ta utilisent désormais une catégorie dédiée non alimentaire :

```text
ressources brutes
    ↓
produits biologiques Goa'uld
    ↓
larve de Prim'ta
```

Cette catégorie évite deux classements inadaptés :

```text
produits manufacturés
produits animaliers crus alimentaires
```

## Audit futur

Avant la stabilisation finale, les catégories de tous les objets du mod seront
revues : biologie Goa'uld, symbiotes, objets rituels, technologies, équipements
Jaffa, médicaments, trétonine et ressources de factions.


## Produits médicaux Goa'uld

Depuis `0.1.36-dev`, les doses de trétonine utilisent :

```text
produits manufacturés
    ↓
produits médicaux Goa'uld
```

Cette catégorie dédiée évite que la trétonine soit consommée comme médicament
vanilla générique.
