# Tok'ra organic operation opportunities

Tok'ra cells do not immediately entrust a new colony with sabotage or other sensitive missions. They may first open brief, cautious channels and ask for low-sensitivity assistance.

## Discreet observation request

The first organic opportunity asks the colony to watch for unusual Goa'uld activity and later transmit a concise report.

Requirements:

- a player-controlled home map;
- a powered Tok'ra secure communicator;
- a colon capable of Intellectual work to operate the communicator.

The request can arrive before the Tok'ra relationship reaches the Trusted tier. This provides a gradual path from initial neutral trust toward access to more sensitive operations.

## Player interaction

When the request arrives:

1. Select a colon.
2. Right-click the powered Tok'ra secure communicator.
3. Accept the observation request.
4. Wait until the observation period is complete.
5. Use the communicator again to transmit the report before the secure window closes.

A successful report improves Tok'ra trust slightly and grants a small amount of Intellectual experience to the operator.

Ignoring an unsolicited offer does not reduce trust. Accepting the request and then missing the reporting window makes the cell slightly more cautious.

## Hidden timing

Organic requests use variable hidden delays. The communicator status report shows only the current request state, not the exact schedule of future contacts.

## Trusted operations remain distinct

Manual support requests and sensitive missions, including relay sabotage, retain their existing Trusted-tier requirements. Preliminary organic requests are tests of reliability, not unrestricted access to the Tok'ra support network.
