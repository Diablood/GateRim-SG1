# Tok'ra mission objects

The `0.3.95-dev` visual pass gives the recurring Tok'ra mission framework a
distinct set of readable objects instead of reusing one generic data packet or
the secure communicator.

## Validated objects

| Object | Role | Media |
|---|---|---|
| Tok'ra cipher module | Introduction artifact analyzed to unlock secure communications | ![Tok'ra cipher module](images/SG1_TokraIntroductionArtifact.png) |
| Encoded intelligence packet | Portable recovered intelligence container | ![Encoded intelligence packet](images/SG1_TokraMissionIntelPacket.png) |
| Observation device | Portable sensor and deployed observation point | ![Observation device](images/SG1_TokraObservationDevice.png) |
| Organic dead drop | Concealed biological-looking clandestine cache | ![Organic dead drop](images/SG1_TokraOrganicDeadDrop.png) |
| Goa'uld relay control node | Sabotage target inside the relay operation | ![Goa'uld relay control node](images/SG1_TokraRelaySabotageDevice.png) |
| Tok'ra secure communicator | Permanent powered link to the Tok'ra operation network | ![Tok'ra secure communicator](images/SG1_TokraSecureCommunicator.png) |
| Priority delivery marker | Semi-transparent ground marker showing the preferred drop location | ![Priority delivery marker](images/SG1_TokraDeliveryDropSpot.png) |

All event-site icons under `Textures/World/WorldObjects/Expanding/Sites` are
already validated final world-map art and are not part of this replacement lot.
