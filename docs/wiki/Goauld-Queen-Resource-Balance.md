# Équilibrage des Prim'ta de reine

> Statut : Équilibrage jouable  
> Première version : 0.2.11-dev

## Objectif

L'arrivée naturelle d'une reine Goa'uld ouvre une boucle normale pour obtenir
des Prim'ta, mais cette boucle doit rester rare et précieuse.

Le premier équilibrage ralentit donc la production issue d'une reine isolée.

## Arrivée naturelle

```text
jour minimal : 45
chance de base : 0,015
délai minimal : 90 jours
```

L'incident reste refusé si une reine Goa'uld vivante contrôlée par le joueur
existe déjà sur une carte ou dans une caravane.

## Extraction

Une extraction produit toujours :

```text
1 symbiote immature de Prim'ta
```

Mais la reine a maintenant besoin de :

```text
3 jours RimWorld
```

avant une nouvelle extraction.

## Maturation assistée

La transformation en larve de Prim'ta implantable demande maintenant :

```text
1 symbiote immature
20 unités de viande crue
recherche : Biotechnologies Goa'uld
bassin d'incubation Prim'ta
```

La compétence Animaux requise reste inchangée.

## Effet attendu

Une reine contrôlée par le joueur devient une ressource biologique stratégique,
pas une usine quotidienne de larves.

De futures infrastructures spécialisées pourront améliorer ce rendement, mais
elles devront demander un investissement visible.
