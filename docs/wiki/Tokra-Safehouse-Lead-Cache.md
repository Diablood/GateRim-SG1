# Cache découvert grâce à une piste Tok'ra

> Statut : Première base jouable  
> Première version : 0.2.15-dev

## Présentation

Les pistes de planque Tok'ra peuvent maintenant être exploitées avant l'arrivée
des vrais sites cachés.

Lorsqu'une piste est exploitée, elle mène à un petit cache médical sur la carte
active.

## Conditions

L'événement demande :

```text
au moins 1 piste de planque Tok'ra
confiance Tok'ra au moins neutre
```

## Effet

En cas de réussite :

```text
-1 piste de planque Tok'ra
2 doses de trétonine
3 médicaments industriels
```

## Limites

Le cache ne crée toujours pas :

- de site mondial ;
- de carte secondaire ;
- de colonie ;
- de caravane ;
- de visiteurs ;
- de marchand ;
- de recrutement ;
- d'aide militaire ;
- de raid.

Les vraies planques visitables restent prévues pour un jalon ultérieur.
