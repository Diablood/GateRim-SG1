# Loadouts d'armures Jaffa

> Statut : Prototype
> Version d'introduction : 0.1.68-dev

## Présentation

Les serviteurs Jaffa Goa'uld générés reçoivent désormais automatiquement
leur ensemble d'armure modulaire.

## Guerrier Jaffa Goa'uld

```text
armure Jaffa légère
gantelets blindés Jaffa
bottes renforcées Jaffa
casque Jaffa rétractable
bâton Ma'Tok
Prim'ta initial
```

## Garde Jaffa Goa'uld

```text
armure Jaffa lourde
gantelets blindés Jaffa
bottes renforcées Jaffa
casque Jaffa rétractable
bâton Ma'Tok
Prim'ta initial
```

## Casque rétractable

Le casque est généré en position déployée, puis son mode persistant est
appliqué normalement. En mode automatique, il se rétracte lorsque le porteur
n'est pas enrôlé et se déploie pendant l'enrôlement.

## Limites du prototype

Les textures sont temporaires. Les raids, colonies et marchands Goa'uld
naturels restent désactivés.
