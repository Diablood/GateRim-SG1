# Reine Goa'uld

> Statut : Prototype
> Version d'introduction : 0.1.57-dev

## Présentation

Les reines Goa'uld sont la future origine biologique des symbiotes immatures.
Ce premier jalon ajoute une reine distincte, générable uniquement en mode
développeur.

```text
reine Goa'uld
```

## Fonctionnement actuel

La reine est volontairement passive :

- elle n'effectue aucune implantation ;
- elle ne chasse aucun humanoïde ;
- elle ne produit pas encore de larves ;
- elle n'apparaît pas naturellement ;
- elle ne rejoint pas encore une faction Goa'uld.

Sa texture est temporaire : elle réutilise visuellement le prototype de symbiote
adulte avec une taille d'affichage supérieure.

## Suite prévue

Le prochain lot biologique devra relier la reine à une source contrôlée de
symbiotes immatures. Le bassin d'incubation du Prim'ta deviendra alors une
infrastructure de maturation assistée plutôt qu'une source entièrement autonome.
