# Reine Goa'uld

> Statut : Prototype
> Version d'introduction : 0.1.57-dev

## Présentation

Les reines Goa'uld sont la future origine biologique des symbiotes immatures.
La reine distincte est générable uniquement en mode développeur. Depuis
`0.1.58-dev`, elle fournit aussi la première source contrôlée de symbiotes
immatures pour la maturation assistée.

```text
reine Goa'uld
```

## Fonctionnement actuel

La reine reste volontairement limitée :

- elle n'effectue aucune implantation ;
- elle ne chasse aucun humanoïde ;
- elle n'apparaît pas naturellement ;
- elle ne rejoint pas encore une faction Goa'uld ;
- son bouton d'extraction est réservé au mode développeur ;
- elle fournit `1` symbiote immature physique avec un délai prototype d'un jour.

Sa texture est temporaire : elle réutilise visuellement le prototype de symbiote
adulte avec une taille d'affichage supérieure.

## Suite prévue

Le bassin d'incubation du Prim'ta est désormais une infrastructure de maturation
assistée. Les prochains lots devront remplacer l'extraction développeur par une
disponibilité naturelle ou factionnelle correctement équilibrée.

Consulte [Maturation assistée des Prim'ta](Goauld-Queen-Assisted-Maturation).
