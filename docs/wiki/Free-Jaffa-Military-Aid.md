# Aide militaire des Jaffa libres

> Statut : contenu jouable
> Version : `0.3.44-dev`

## Principe

Une faction **Jaffa libres** devenue alliée peut répondre à une demande d'aide militaire transmise depuis une console de communication alimentée.

Cette intervention utilise le dialogue diplomatique ordinaire de RimWorld. Le mod n'ajoute ni monnaie spéciale, ni nouvelle jauge de confiance, ni mission parallèle.

## Conditions

Le joueur doit :

- disposer d'une console de communication alimentée ;
- envoyer un colon capable d'utiliser la console ;
- avoir atteint le statut allié avec les Jaffa libres ;
- pouvoir payer le coût de bonne volonté demandé par RimWorld ;
- ne pas être bloqué par le délai de nouvelle demande.

Une faction neutre ou hostile ne propose pas cette aide.

## Renforts

La force utilise les profils militaires existants :

```text
guerrier Jaffa libre
garde Jaffa libre
```

Les renforts conservent :

- leur xénotype Jaffa ;
- leur Prim'ta ;
- leurs noms et parcours culturels ;
- leurs bâtons Ma'Tok et armures modulaires ;
- l'absence de marque frontale Goa'uld imposée.

Leur nombre, leur arrivée, leur comportement au combat et leur départ restent gérés par RimWorld.

## Limites

Cette possibilité n'active pas :

- les quêtes propres aux Jaffa libres ;
- leurs raids naturels ;
- les sièges ;
- les attaques préparées ;
- un recrutement automatique des survivants.

Le [commerce Jaffa libre](Free-Jaffa-Trade) et les [visiteurs pacifiques](Free-Jaffa-Peaceful-Visitors) restent des systèmes distincts.
