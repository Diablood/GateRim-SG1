# Production de trétonine

> Statut : Prototype  
> Version d'introduction : 0.1.37-dev

## Présentation

La trétonine peut désormais être produite sans utiliser le mode développeur.

Cette première version utilise le laboratoire de drogues vanilla :

```text
DrugLab
```

## Recette

```text
préparer des doses de trétonine
```

| Élément | Valeur |
|---|---:|
| Atelier | Laboratoire de drogues vanilla |
| Travail | Intellectuel |
| Compétence minimale | `6` |
| Larve de Prim'ta | `1` |
| Médicament | `1` |
| Doses obtenues | `5` |

## Boucle gameplay

```text
incuber une larve de Prim'ta
    ↓
choisir son utilisation
    ├── implantation permanente chez un Jaffa
    └── transformation en 5 doses de trétonine
```

pourra ajouter :
