# Installation et dépendances

> Statut : Implémenté  
> Version d'introduction : 0.1.6-dev

## Version prise en charge

```text
RimWorld 1.6
```

## Dépendance requise

```text
Biotech
```

Biotech est nécessaire pour charger le xenotype Jaffa et les gènes personnalisés.

## Installation manuelle

Place le dossier du mod dans le répertoire local des mods RimWorld, puis active :

```text
Core
Biotech
GateRim SG-1
```

## Tests de compatibilité

Pendant la phase de développement, teste d'abord GateRim SG-1 avec la liste minimale ci-dessus. Réactive ensuite les autres mods progressivement afin d'identifier plus facilement les incompatibilités éventuelles.
