# Recherches de fabrication Stargate

> Statut : Implémenté
> Première version : 0.2.8-dev
> Validation complète : 0.2.8-dev-r1

## Présentation

La fabrication locale des équipements Stargate n'est plus disponible
immédiatement après la construction des établis vanilla.

GateRim SG-1 ajoute un onglet de recherche dédié :

```text
GateRim SG-1
```

Les recherches représentent l'analyse, l'adaptation et la reproduction locale
de technologies récupérées ou connues.

Les objets déjà obtenus restent utilisables avant la fin de ces recherches.

L'onglet, les prérequis, les verrouillages de production et les
déblocages correspondants ont été validés en jeu.

## Armement Jaffa

```text
prérequis vanilla : Petite armurerie
```

Débloque la fabrication locale :

- du bâton Ma'Tok ;
- du Zat'nik'tel.

## Armures Jaffa

```text
prérequis vanilla : Vêtements pare-balles
```

Débloque la fabrication locale :

- de l'armure Jaffa légère ;
- de l'armure Jaffa lourde ;
- des gantelets Jaffa ;
- des bottes renforcées Jaffa ;
- du casque Jaffa déployé.

## Kara kesh

```text
prérequis GateRim SG-1 : Armures Jaffa
```

Débloque la fabrication locale du kara kesh porté naturellement par les Grands
Maîtres Goa'uld. Son premier mode implémenté est le bouclier personnel. Les
exemplaires récupérés restent utilisables avant la fin de cette recherche.

## Équipement de terrain du SGC

```text
prérequis vanilla : Vêtements complexes
```

Débloque la fabrication locale :

- du treillis d'équipe SG et de ses variantes ;
- des bottes tactiques SG ;
- des gants tactiques SG ;
- du gilet tactique SG ;
- du casque de terrain SG.

## Biotechnologies Goa'uld

```text
prérequis vanilla : Production de drogues
```

Débloque :

- la préparation de trétonine ;
- la maturation assistée des larves de Prim'ta ;
- le bassin d'incubation Prim'ta ;
- le bassin de préservation Prim'ta ;
- le bassin rituel Goa'uld.

## Utilisation des objets récupérés

Ces recherches verrouillent seulement la production locale.

Avant leur achèvement, la colonie peut toujours :

- utiliser un Ma'Tok ou un Zat'nik'tel récupéré ;
- porter une armure Jaffa capturée ;
- porter un kara kesh capturé ;
- utiliser l'équipement SG fourni par le scénario ;
- administrer une dose de trétonine déjà obtenue ;
- implanter une larve de Prim'ta disponible.

Les futures sources normales de ressources rares seront ajoutées dans un
jalon séparé.
