# Cache médicale d'urgence Tok'ra

> Statut : prototype
> Version d'introduction : 0.2.30-dev

La cache médicale d'urgence est une demande fiable via le communicateur sécurisé
Tok'ra. Elle représente une aide matérielle ponctuelle, pas un commerce.

## Conditions

```text
confiance Tok'ra au palier fiable
communicateur sécurisé construit et alimenté
colon sélectionné utilisant le communicateur
au moins un colon humain blessé ou malade sur la carte
délai de cache disponible
```

## Effet

```text
le colon utilise le communicateur
une petite cache apparaît près du communicateur
contenu limité : quelques médicaments et une dose de trétonine si disponible
le canal de cache entre en silence pendant environ 7 jours
```

## Limites

```text
pas de soin direct
pas de livraison régulière
pas de commerce
pas de recrutement
pas de quête
pas d'aide militaire
```

Cette demande sert de première récompense matérielle Tok'ra fiable, tout en
restant rare et défensive.
