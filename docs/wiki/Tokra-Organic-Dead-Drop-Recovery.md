# Analyse d'un module de renseignements Tok'ra

Une cellule Tok'ra peut confier à la colonie un module scellé contenant des renseignements chiffrés sur une activité Goa'uld.

## Accepter la demande

L'offre arrive par le canal Tok'ra. Un colon capable d'Intellectuel peut l'accepter depuis un communicateur sécurisé alimenté. Ignorer l'offre n'a aucune conséquence sur la confiance.

Après acceptation, le module est livré selon cet ordre de priorité :

1. sur la zone de livraison Tok'ra ou juste à côté ;
2. près d'un communicateur Tok'ra alimenté ;
3. près d'un bord de carte accessible, uniquement en dernier recours.

Le module est généré uniquement pour cette opération. Il n'apparaît pas dans le menu Architecte, ne peut pas être construit et ne contient aucune fourniture récupérable.

## Choisir une méthode d'analyse

Le module ne peut pas être analysé directement ni depuis une table de recherche. Sélectionnez un colon capable d'Intellectuel, puis utilisez le communicateur Tok'ra alimenté.

Après le choix de la méthode, le colon se rend d'abord jusqu'au module, le transporte physiquement au communicateur, puis commence seulement l'analyse. Une interruption peut laisser le module au sol ; l'opération reprend ensuite depuis le communicateur.

Deux méthodes sont proposées :

- **Analyse prudente** : plus longue, mais conçue pour maintenir la transmission sous contrôle.
- **Décodage accéléré** : plus rapide et plus formateur, mais susceptible de produire une interférence détectable.

Une fois la méthode choisie, elle reste fixée pour cette occurrence. Le travail peut être interrompu puis repris, y compris après une sauvegarde.

## Résultats possibles

Une analyse réussie améliore qualitativement la confiance Tok'ra et accorde de l'expérience en Intellectuel. Les renseignements obtenus varient d'une occurrence à l'autre : routes logistiques, fréquences de commandement, calendriers de relais ou mouvements de patrouilles peuvent être évoqués.

Le décodage accéléré peut laisser échapper une signature. Dans ce cas, l'opération reste réussie, mais une petite patrouille Goa'uld/Jaffa présente dans la région peut venir rechercher l'origine du signal quelques heures plus tard.

La perte du module ou l'expiration d'un engagement accepté rend la cellule plus prudente. Une offre simplement ignorée ne provoque aucune pénalité.

## Informations du canal

En jeu normal, le communicateur affiche uniquement l'opération actuellement proposée ou active, ainsi que les étapes durables pertinentes des missions uniques déjà accomplies. Il ne révèle pas les futures opérations, les délais cachés, les pondérations ou l'historique technique.
