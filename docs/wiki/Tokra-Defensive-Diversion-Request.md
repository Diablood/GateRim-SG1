# Diversion défensive Tok'ra

> Statut : prototype
> Version d'introduction : 0.2.27-dev

La diversion défensive est la première aide active disponible via le
[communicateur sécurisé Tok'ra](Tokra-Secure-Communicator).

## Conditions

```text
confiance Tok'ra au palier fiable
communicateur sécurisé construit et alimenté
menace hostile active sur la carte
délai de diversion disponible
```

## Effet

```text
une cellule Tok'ra perturbe discrètement l'attaque
jusqu'à 3 ennemis sont brièvement désorganisés
l'effet combine une courte interruption immédiate et des nausées retardées pour les cibles biologiques
le canal entre ensuite en silence radio pendant plusieurs jours
```

## Ce que cela ne fait pas

```text
pas de renfort Tok'ra physique
pas d'attaque offensive à distance
pas de commerce
pas de recrutement
pas de récompense matérielle
pas de quête
```

Cette aide sert à donner une première valeur concrète au palier fiable sans
remplacer les défenses de la colonie ni créer une alliance militaire ouverte.
