# Implantation thérapeutique Tok'ra

> Statut : Prototype
> Version d'introduction : 0.1.45-dev

## Principe

Un symbiote Tok'ra libre dispose désormais d'une action dédiée pour proposer
une implantation thérapeutique volontaire à un humanoïde malade compatible.

Le premier prototype impose les conditions suivantes :

```text
humanoïde compatible
contrôlé par le joueur
proche du symbiote Tok'ra
atteint d'au moins une pathologie grave configurée
```

Après la sélection de la cible, une fenêtre demande une confirmation explicite
avant le transfert.

## Après l'implantation

Le pawn passe par la conversion d'implantation déjà existante avant de devenir
un hôte Tok'ra actif durable. Le symbiote peut alors retirer automatiquement
les pathologies graves configurées grâce au prototype d'hébergement
thérapeutique.

## Limites actuelles

```text
règles encore définies dans le code
pas de sélection automatique
pas de chirurgie médicale dédiée
pas encore de quête ou d'événement de recrutement
```

L'implantation volontaire Tok'ra générique reste également disponible.
