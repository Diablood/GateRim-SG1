# Development conventions

## General
- Use 4 spaces for indentation when applicable.
- Keep XML files focused: one coherent content group per file.
- Prefer readable `SG1_` prefixes for RimWorld `defName` values.
- Preserve `About/ModIcon.png` in every release archive.
- Test each incremental batch before adding the next one.

## C#
- Namespace: `GateRimSG1`
- Source directory: `Source/GateRimSG1`
- Add C# only when XML is not sufficient.

## Suggested commit for this skeleton
```text
0.1.0-dev - Initialize GateRim SG-1 foundation
```
