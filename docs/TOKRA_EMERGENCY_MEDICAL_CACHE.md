# Tok'ra emergency medical cache request

Version: `0.2.30-dev`

This milestone adds a limited material support request to the pawn-operated
Tok'ra secure communicator. It is intended as emergency support, not trade or a
repeatable supply chain.

## Player-facing behavior

```text
select a player colonist
right-click the Tok'ra secure communicator
request Tok'ra emergency medical cache
colon operates the communicator briefly
small cache is placed near the communicator
```

## Requirements

```text
trusted Tok'ra trust tier
powered communicator
at least one wounded or sick human colonist on the map
cache cooldown available
```

## Current reward

```text
small amount of industrial medicine
one tretonin dose when the def is available
seven-day dedicated cooldown
```

## Boundaries

```text
no direct healing
no trade
no recruitment
no quest
no military aid
no permanent supply chain
```
