# Culture-specific pawn names

## Goal

`0.3.5-dev` adds a first internal naming layer for pawns generated by GateRim SG-1 factions and PawnKinds.

The system covers:

- Goa'uld-aligned Jaffa;
- Free Jaffa;
- Goa'uld and their generated host castes;
- Tok'ra and generated voluntary hosts;
- Tau'ri / SGC expedition pawns.

The generated names are original culture-inspired combinations rather than a short list copied from known Stargate characters. The pools are deliberately combinatorial so recurring visitors, raids and long games retain useful variety.

## Assignment rules

The `GameComponent_CulturalPawnNameManager` scans newly generated map pawns, faction leaders and world pawns. A lightweight pawn comp also notifies the relevant host initializer and the manager immediately when compatible pawns spawn, including through the vanilla developer `Spawn pawn` tool while paused.

A pawn receives at most one cultural-name assignment:

- Goa'uld-aligned Jaffa PawnKinds use the Goa'uld-domain Jaffa generator;
- Free Jaffa PawnKinds and faction members use the Free Jaffa generator;
- generated Goa'uld host PawnKinds use the Goa'uld generator;
- generated Tok'ra voluntary hosts and Tok'ra faction members use the Tok'ra generator;
- pawns generated for the SGC expedition faction use the Tau'ri generator.

Existing pawns are protected:

- when the feature is first loaded into a pre-`0.3.5-dev` save, every existing pawn is registered without renaming;
- the stranded SG-team scenario generates Tau'ri names for its candidates before player configuration; any manual name chosen by the player remains protected after the game starts;
- after a pawn has been processed, later recruitment, medical changes, implantation, extraction or faction changes do not rename it again.

The manager persists processed pawn IDs and reserved generated names in the save.

## Host and symbiote identity

`GoauldSymbioteData` now stores both:

- `symbioteName`;
- `hostName`.

When a generated Goa'uld or Tok'ra host is initialized, the original human name is captured before the visible pawn receives its culture-specific identity. The symbiote identity remains attached to the persistent symbiote data through implantation, extraction and transfer.

This milestone only prepares the distinction. It does not yet expose both names in every player-facing interface.

## Debug access

The existing `GateRim SG-1` developer category exposes the grouped culture submenu:

```text
GateRim SG-1 → Culture... → Show cultural name samples
```

The same sample report is available from the GateRim SG-1 settings page when advanced debug information is enabled.

The report generates examples for all five current cultural groups without creating or renaming pawns.

## Future extension

The generator is intentionally isolated from the faction definitions so future Asgard, Nox, Unas and other GateRim SG-1 cultures can add their own pools without changing the existing naming rules.

## Supported generation tests

A Goa'uld raid is a valid natural-generation test because the mod provides dedicated Goa'uld raid incidents. Generic vanilla raids are not valid for every culture: Tok'ra and Free Jaffa currently forbid raids, while the SGC expedition is a player faction. Test those cultures through supported visitors, faction leaders, direct PawnKind spawning or the stranded SG-team scenario instead.
